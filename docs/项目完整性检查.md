## 三、与产品/架构文档对照

- **已具备**：仓库拆分（apps/web、apps/admin）、根首页与 Admin 占位页、Prisma 数据模型（Category/Album/Episode）、MySQL 配置、本地与远程运行脚本、部署与 PM2 配置、产品与架构文档。
- **未实现**：C 端分类/搜索/专辑详情/播放器/我的/登录及对应 API；Admin 分类与专辑/节目 CRUD、上传、登录；Web 的 components/lib/stores、种子数据、Tailwind 配置文件。

---

## 四、建议补全顺序

1. **apps/web**：补全 `app/api`（albums、categories、episodes）、专辑列表首页与专辑详情页、再补播放器（stores + 播放页）。
2. **apps/admin**：补全分类/专辑/节目 CRUD 与 `app/api`，再补登录与上传（封面/音频）。
3. **apps/web**：`prisma/seed.ts`、Tailwind/PostCSS 配置（若采用 Tailwind）。
4. **可选**：C 端「我的」、历史、收藏、登录与进度同步。
