# HarryListenly 管理后台 — 产品文档

> 面向运营/编辑的内容管理后台 PRD，与 C 端听书应用配套使用。

---

## 一、产品概述

### 1.1 产品定位

**HarryListenly 管理后台** 为听书应用提供**内容管理能力**：管理分类、专辑、节目（单集），上传封面与音频，与 C 端共用同一 MySQL 数据库，保证前台展示与播放数据一致。

### 1.2 目标用户

| 角色     | 使用场景                     |
|----------|------------------------------|
| 运营/编辑 | 上架专辑、维护节目列表、上传音频与封面 |
| 管理员   | 管理分类、审核内容、系统设置（可选） |

### 1.3 与 C 端关系

- **数据一致**：后台增删改的**分类、专辑、节目**即 C 端首页/分类/专辑详情的数据源。
- **存储一致**：音频采用「先本地磁盘、后续迁 OSS」方案；后台上传的音频与封面存放位置与 C 端 `audio_url` / 封面 URL 约定一致（如相对路径 `/audio/{albumId}/{episodeId}.mp3`）。

## 三、功能说明

### 3.1 登录与鉴权

| 功能     | 说明 |
|----------|------|
| 登录页   | 账号 + 密码（或简单固定密码），登录成功后写 Session/Token，跳转工作台。 |
| 登出     | 清除会话，返回登录页。 |
| 鉴权     | 未登录访问任意后台页面时重定向到登录页。 |
| V1 简化  | 可先采用**固定账号密码**或**环境变量配置**，不做完整用户表与权限体系；后续可加 Admin 用户表与角色。 |

### 3.2 工作台（首页）

| 内容     | 说明 |
|----------|------|
| 概览     | 可选：专辑总数、节目总数、分类数、最近更新专辑。 |
| 快捷入口 | 进入「分类管理」「专辑管理」的入口。 |

### 3.3 分类管理

| 功能     | 说明 |
|----------|------|
| 分类列表 | 表格或树形展示所有分类；支持一级分类（可扩展子分类）。 |
| 新增分类 | 填写名称、可选封面图、可选父级分类。 |
| 编辑分类 | 修改名称、封面、父级。 |
| 删除分类 | 删除前校验是否有关联专辑；有关联时提示不可删或先迁移。 |

### 3.4 专辑管理

| 功能     | 说明 |
|----------|------|
| 专辑列表 | 表格展示：封面、标题、作者、分类、节目数、更新时间；支持按分类筛选、搜索标题/作者。 |
| 新增专辑 | 填写标题、作者、分类、简介；上传封面图；保存后生成专辑 ID，再可添加节目。 |
| 编辑专辑 | 修改标题、作者、分类、简介、封面。 |
| 删除专辑 | 删除专辑时可选是否同时删除其下所有节目（逻辑与 Prisma/DB 一致）。 |

### 3.5 节目（单集）管理

| 功能     | 说明 |
|----------|------|
| 节目列表 | 进入某专辑后展示该专辑下所有单集：标题、时长、音频 URL/路径、排序、创建时间。 |
| 新增单集 | 填写标题、上传音频文件（保存到约定目录，如 `public/audio/{albumId}/{episodeId}.mp3` 或先上传再填路径）；时长可自动解析或手动填写。 |
| 编辑单集 | 修改标题、音频（重新上传或改路径）、时长、排序。 |
| 删除单集 | 删除单集记录；是否同时删除服务器上的音频文件可选。 |
| 排序     | 支持拖拽排序或填写排序号，对应 `order` 字段。 |

### 3.6 上传与存储约定

| 资源     | 约定 |
|----------|------|
| 封面     | 存于站点静态资源或统一目录，如 `public/covers/{albumId}.jpg`；数据库中存相对路径如 `/covers/xxx.jpg`。 |
| 音频     | 先本地磁盘：存于 `public/audio/{albumId}/{episodeId}.mp3`（或与主项目约定一致）；数据库中 `episode.audio_url` 存相对路径如 `/audio/album1/ep1.mp3`。后续迁 OSS 时，后台改为上传至 OSS 并写 OSS 路径或 key。 |

## 四、信息架构（IA）

```
/admin                   登录页（未登录时）
/admin/dashboard         工作台（登录后首页）
/admin/categories        分类列表
/admin/categories/new    新增分类
/admin/categories/[id]   编辑分类
/admin/albums            专辑列表
/admin/albums/new        新增专辑
/admin/albums/[id]       编辑专辑
/admin/albums/[id]/episodes    某专辑的节目列表
/admin/albums/[id]/episodes/new 新增节目
/admin/albums/[id]/episodes/[eid]  编辑节目
```

## 五、非功能需求

| 类型     | 要求 |
|----------|------|
| 设备     | 以 PC 端浏览器为主，响应式即可，不强制移动端。 |
| 安全     | 仅内网或限定 IP 访问（可选）；登录态 Cookie/Token；敏感操作可加二次确认。 |
| 性能     | 列表分页；上传大文件时支持进度与超时配置。 |
