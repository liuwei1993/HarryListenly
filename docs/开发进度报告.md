## 二、听书应用（apps/web）已完成

- **首页**：专辑列表（Prisma），入口到专辑详情。
- **分类**：`/category` 分类列表，`/category/[id]` 分类下专辑列表。
- **专辑详情**：`/album/[id]` 展示专辑信息与节目列表，每集「播放」写入播放器状态。
- **播放器**：底部 PlayerBar、全屏 `/play`（进度条、倍速 0.75x～2x、上一集/下一集）；Zustand 状态 + `lib/useAudio.ts` 封装 HTML5 Audio。
- **我的**：`/me`、`/me/history`、`/me/favorites` 占位页。
- **API**：`/api/categories`、`/api/albums`、`/api/albums/[id]`、`/api/albums/[id]/episodes`。
- **数据**：Prisma + MySQL（Category、Album、Episode），`prisma/seed.ts` 示例数据。
- **工程**：Tailwind/PostCSS 配置、类型定义、`lib/audio`（兼容后续迁 OSS）。

---

## 三、管理后台（apps/admin）已完成

- **登录**：`/login` 密码登录，Cookie `admin_session`，环境变量 `ADMIN_PASSWORD`（默认 admin123）。
- **鉴权**：`middleware.ts` 未登录重定向 `/login`，已登录访问 `/login` 重定向首页。
- **分类**：列表（含专辑数）、新增、编辑、删除；有关联专辑时禁止删除分类。
- **专辑**：列表、新增、编辑、删除；新增后跳转该专辑节目列表。
- **节目**：按专辑的节目列表、新增、编辑、删除；删除时更新专辑 `episodeCount`。
- **API**：`/api/auth/login`、`/api/auth/logout`；分类/专辑/节目完整 CRUD。
- **首页**：工作台 / 分类 / 专辑入口 + 退出。

## 四、基础设施与脚本

- **仓库**：根 workspace，`apps/web`、`apps/admin` 分离。
- **脚本**：`install.sh`、`dev-web.sh`、`dev-admin.sh`、`dev-all.sh`、`build.sh`、`db-push.sh`、`db-seed.sh`、`deploy.sh`。
- **部署**：`deploy.sh` 同步至 `root@harry.help`，远程 `npm install` + 构建 + PM2；Web 8001、Admin 8002；`ecosystem.config.js` 已配置。
- **配置**：根目录 `.env.example`、`.gitignore`；各 app 下 `.env`（DATABASE_URL、ADMIN_PASSWORD）本地/服务器自配。
