## 一、产品概述

### 1.1 产品定位

**HarryListenly** 是一款前后端一体的**手机 Web 听书应用**，用户通过浏览器即可收听有声书、播客、课程等音频内容，无需安装 App。产品参考喜马拉雅的核心体验，聚焦「发现 — 收听 — 收藏 — 续听」闭环。

### 1.2 目标用户

| 用户类型     | 典型场景                     |
|-------------|------------------------------|
| 通勤/运动用户 | 碎片时间听小说、播客         |
| 学习用户     | 听知识课程、外语、有声书     |
| 睡前/放松用户 | 听助眠、轻音乐、故事         |

### 1.3 核心价值

- **即开即用**：H5 打开即听，无需下载
- **多端同步**：登录后收听进度、收藏、历史可同步
- **内容分层**：免费试听 + 会员/付费专辑，可持续运营

## 三、功能说明（参考喜马拉雅）

### 3.1 首页（发现）

| 模块       | 说明 |
|------------|------|
| 顶部 Banner | 运营位，可配置活动/专辑入口 |
| 推荐/精选   | 编辑精选或算法推荐的专辑/单集 |
| 热门榜单   | 如「畅销榜」「新书榜」「完结榜」 |
| 分类快捷入口 | 小说、知识、儿童、助眠等大类 |
| 猜你喜欢   | 基于历史与偏好的个性化推荐 |

### 3.2 分类与搜索

| 功能     | 说明 |
|----------|------|
| 分类浏览 | 树形分类：小说、知识、播客、儿童、助眠等，可下钻到子类 |
| 关键词搜索 | 支持专辑名、节目名、主播/作者名 |
| 搜索结果 | 专辑列表、单集列表、主播列表，支持筛选与排序 |

### 3.3 专辑/节目详情

| 元素       | 说明 |
|------------|------|
| 封面/简介  | 封面图、标题、主播、播放量、订阅数、简介 |
| 节目列表   | 分集列表，支持正序/倒序，显示时长与更新日期 |
| 操作       | 订阅/收藏、分享、立即播放/续播、下载（可选） |

### 3.4 播放器（核心）

| 能力       | 说明 |
|------------|------|
| 播放/暂停  | 支持播放、暂停、上一集、下一集 |
| 进度控制   | 进度条拖动、当前时间/总时长展示 |
| 倍速       | 0.5x、0.75x、1x、1.25x、1.5x、2x 等 |
| 定时关闭   | 如「本集结束」「15/30/60 分钟后」 |
| 播放列表   | 当前专辑队列，可删减、排序（可选） |
| 续听       | 记录上次播放位置，下次打开从断点续播 |

### 3.5 我的（个人中心）

| 功能       | 说明 |
|------------|------|
| 收听历史   | 按时间展示听过的专辑/单集，支持清除 |
| 收藏/订阅  | 我收藏的专辑与单集，可取消 |
| 播放列表   | 当前播放队列的持久化（可选） |
| 账号与设置 | 登录/登出、昵称头像、播放偏好（如默认倍速）、隐私设置 |

### 3.6 用户与账号（V1 可简化）

- **游客**：可浏览、试听，进度仅存本地（localStorage）
- **登录用户**：手机号/邮箱注册登录，进度与收藏云端同步
- **会员/付费**（可选）：会员专享专辑、单集购买，后续迭代

## 四、关键业务流程

### 4.1 听书主流程

```
进入首页 → 浏览/搜索 → 进入专辑详情 → 选择单集 → 进入播放页
    → 播放/暂停/切集/倍速/定时 → 退出（进度自动保存）→ 再次进入可续听
```

### 4.2 续听流程

```
打开 App → 检测本地/云端上次播放 → 若有则展示「续听」入口
    → 用户点击 → 直接进入播放页并从断点播放
```

### 4.3 收藏与历史

```
在专辑详情/播放页 → 点击收藏 → 写入「我的收藏」
在「我的」→ 收听历史 → 展示最近播放列表 → 点击可继续听
```

## 六、非功能需求

| 类型     | 要求 |
|----------|------|
| 兼容性   | 主流移动端浏览器（iOS Safari、Android Chrome），响应式布局 |
| 性能     | 首屏可交互 &lt; 3s，播放器切换流畅，支持弱网 |
| 音频     | 支持 MP3/AAC，断点续传与缓冲策略 |
| 数据     | 播放进度、收藏、历史需持久化（本地 + 登录后云端） |
| 安全     | 登录态 Token、HTTPS、敏感接口鉴权 |

## 七、版本规划建议

| 版本  | 范围 |
|-------|------|
| **V0.1** | 首页静态展示、专辑详情、基础播放器（播放/暂停/进度/倍速）、本地进度与历史 |

| **V1.0** | 推荐/榜单、会员或付费单集（可选）、基础数据统计 |
